# Hambre y sed de justicia — Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Crear tres muestras visuales 16:9 para aprobar el estilo de las diapositivas de la prédica.

**Architecture:** Generar una ilustración editorial plana para cada concepto y componer el texto exacto como parte de la imagen final. Las tres piezas compartirán paleta, distribución y jerarquía.

**Tech Stack:** Generación de imágenes integrada y validación visual.

## Global Constraints

- PNG de 1920 × 1080 px.
- Fondo crema, naranja intenso, negro y acentos verdes.
- Texto enorme, claro y de alto contraste.
- Sin párrafos ni texto secundario innecesario.
- Logo de El Renuevo pequeño y discreto.
