Read the `readme.md` file within this skill, and explore the other available files
(`styles.css`, `tokens/`, `components/core/`, `slides/`, `guidelines/`, `assets/`).

The brand in one line: warm **cream** canvas, **deep-ink** black, single **lime-green**
accent; heavy **Anton** uppercase titles, **Montserrat** body, a signature green-marker
highlight, and **Playfair Display italic** scripture. All copy is in **Spanish**. The bare
green "R" mark sits discreetly top-right on every slide.

If creating visual artifacts (slides, mocks, throwaway prototypes), copy assets out of
`assets/` and build static HTML files for the user to view — reuse the slide archetypes in
`slides/` (portada, punto, subpunto, aplicación, cierre). If working on production code, copy
the assets and read the rules here to design as an expert in this brand.

If the user invokes this skill without other guidance, ask what they want to build or design,
ask a few focused questions (which meeting, the sermon title/scripture, how many points,
whether they have photos), and act as an expert designer who outputs HTML artifacts _or_
production code, depending on the need.
