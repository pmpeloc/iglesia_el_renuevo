# Brief para Canva: Presentación base Generación Selfie

## Objetivo

Crear en Canva una presentación base reutilizable para la serie juvenil **Generación Selfie** de la Red de Jóvenes / Raíces.

No debe ser una prédica cerrada, sino una **plantilla editable** para usar en esta enseñanza y en las próximas reuniones de la serie.

## Referencia visual

Inspirarse en la portada del libro **Generación Selfie** de Miguel Oyola:

- Fondo negro o gris muy oscuro.
- Rojo anaranjado intenso como color principal de impacto.
- Blanco para contraste.
- Estética de celular, cámara frontal, selfie, interfaz de foto, redes sociales.
- Títulos fuertes, juveniles, de alto impacto.
- Una tipografía pesada para palabras clave como “SELFIE”.
- Una tipografía más irregular/manual para “Generación”, si Canva propone algo similar.

## Tono

Juvenil, directo, pastoral y desafiante.

Debe sentirse actual, visual, claro y útil para una reunión de jóvenes/adolescentes, sin parecer una presentación corporativa.

## Paleta sugerida

- Negro profundo: `#111111`
- Gris oscuro: `#1E1E1E`
- Blanco: `#FFFFFF`
- Rojo anaranjado principal: `#E84A2A`
- Rojo oscuro/acento: `#B73222`
- Gris claro para texto secundario: `#D9D9D9`

## Elementos visuales recurrentes

- Mockup de celular.
- Marco de cámara/selfie.
- Íconos o recursos de cámara, flash, enfoque, galería, notificación.
- Texturas oscuras o fondos tipo foto desenfocada.
- Barras rojas tipo pincel o bloque.
- Composiciones de alto contraste.
- Espacios preparados para insertar fotos o videos.

## Logo

Usar identidad de Jóvenes / Raíces si está disponible:

- `Identificador.png`: símbolo de huella + cruz.
- Colocar de forma discreta en cierre o esquina inferior, no competir con el título.

## Estructura de slides

### 1. Portada de serie

Título grande:

**GENERACIÓN SELFIE**

Subtítulo editable:

**¿Qué ves cuando te ves?**

Visual:

- Celular o cámara frontal.
- Fondo oscuro.
- Rojo anaranjado en la palabra “SELFIE”.

### 2. Portada del mensaje

Título editable:

**Espíritu, alma y cuerpo**

Campos:

- Texto base.
- Fecha/reunión.
- Red de Jóvenes / Raíces.

### 3. Pregunta disparadora

Slide para una pregunta grande al centro.

Ejemplo:

**¿Qué parte de nosotros está tomando el control?**

### 4. Texto bíblico

Layout sobrio para pasajes bíblicos.

Debe permitir:

- Cita principal.
- Referencia destacada.
- Texto largo sin verse apretado.

### 5. Idea central

Frase grande en pantalla completa.

Ejemplo:

**Lo que alimentamos se fortalece.**

Resaltar una palabra clave en rojo anaranjado.

### 6. Mapa del mensaje

Tres bloques numerados:

1. Espíritu
2. Alma
3. Cuerpo

Debe servir para cualquier mensaje de la serie con tres puntos.

### 7. Punto principal

Slide reutilizable para:

**Punto 1**

Título corto editable + una frase de desarrollo.

### 8. Ilustración visual

Slide con marco de teléfono o espacio multimedia.

Debe permitir insertar:

- Imagen.
- Video.
- Captura.
- Ejemplo visual.

### 9. Contraste espiritual

Dos columnas:

- Carne / Espíritu
- Apariencia / Interior
- Selfie / Verdad
- Lo que muestro / Lo que Dios ve

### 10. Aplicación práctica

Pregunta o desafío en tono inclusivo.

Usar primera persona plural:

**Necesitamos preguntarnos qué estamos alimentando.**

Evitar imperativos directos como “dejá”, “hacé”, “tenés que”.

### 11. Momento de respuesta

Slide minimalista para oración, reflexión o llamado final.

Fondo oscuro, poco texto, ambiente serio.

### 12. Cierre

Texto:

**Red de Jóvenes - Raíces**

Espacio para logo y próxima reunión.

## Instrucciones importantes

- Crear una presentación editable en Canva.
- Que funcione como base reutilizable de la serie.
- Priorizar layouts flexibles antes que contenido definitivo.
- Mantener coherencia visual en todos los slides.
- No usar estética infantil.
- No usar demasiados colores.
- Evitar fondos claros dominantes.
- El resultado debe ser útil para proyectar en pantalla durante la reunión.
